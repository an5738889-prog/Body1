# Body Injury Mod (1.20.1 Forge)

Hệ thống thương tích theo bộ phận + băng gạc.

## Cấp độ
- 0 Xanh: Ổn
- 1 Vàng: Nhẹ (băng được)
- 2 Cam: Chú ý (băng được)
- 3 Đỏ: Cần băng (băng được)
- 4 Nguy kịch: Chỉ táo vàng / táo vàng phù phép

## Item
- Bandage: chữa 1 cấp (1-3)
- Medkit: chữa 2 cấp (1-3)

## Lệnh
- /body — xem tình trạng
- /bodyreset — reset (op)

## Build JAR
Dùng GitHub Actions hoặc IntelliJ: `./gradlew build`
